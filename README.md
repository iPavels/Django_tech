# Django_tech

Учебный проект на Django.

## О проекте

Проект представляет собой простой сайт с двумя страницами — главной и страницей контактов. 
Реализован базовый роутинг, разделение на приложения и рендеринг шаблонов через контроллеры (views).

## Стек технологий

- Python 3.14
- Django 6.0.7
- Poetry — управление зависимостями и виртуальным окружением
